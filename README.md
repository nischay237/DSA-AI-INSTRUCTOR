# DSA AI Instructor — Interactive Algorithm Mentor

An interactive Data Structures & Algorithms (DSA) tutor powered by **Google Gemini 2.5 Flash**. Built to help students understand tough algorithmic concepts through **Hinglish explanations**, **step-by-step code dry-runs**, and **multimodal screenshot analysis**.

## Key Features
- **Hinglish Socratic Tutoring:** Explains complex DSA concepts (Recursion, Trees, Dynamic Programming, Graphs, Pointers) in natural Hinglish with real-world analogies.
- **Multimodal Image & Code Analysis:** Upload handwritten whiteboard diagrams, dry-run tables, or code screenshots for line-by-line debugging.
- **Line-by-Line Memory Dry-Runs:** Traces variable states, pointer positions, and time/space complexity ($O(N)$, $O(\log N)$) in structured markdown tables.
- **Built-in DSA Tutorial Portal:** Quick-start modules covering Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Sorting, and Big-O Notation.
- **Persistent Search History:** Automatically stores recent queries in `localStorage` for instant revisits.
